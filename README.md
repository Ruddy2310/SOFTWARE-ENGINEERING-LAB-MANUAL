## About

Each practical includes:
- **Aim** — the objective of the exercise
- **Theory** — relevant background concepts
- **Procedure** — step-by-step instructions
- **Conclusion** — summary of what was learned

Practical 3 additionally includes a **live, runnable project** (source code, unit tests, API tests, a Postman collection, a JMeter test plan, a Selenium script, and a GitHub Actions CI pipeline that runs automatically on every push).

More practicals will be added as the course progresses.
